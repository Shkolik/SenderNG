IModule.PanelHint = Left | Center | Right | Bottom | Flyout | Menu (modal). User can hide any module in settings (collapsed panel if no visible claimants). Bottom spans full width; Cycle buttons aligned to center panel. MDI input keeps session history (dropdown).

How it maps to ioSender screenshot

Left = your DRO card + Offsets/Signals; Center = Block/Data grid now as TabControl (Program/3D View/Console → now Center tabs); Right = Work Parameters + Coolant/Spindle/Feed; Bottom = State/Home/Unlock/Reset + Cycle Start/Feed Hold/Stop/Rewind + MDI with history; Far-right vertical strip = Flyouts (Jog/Macros/Goto/Outline) only if claimed.
